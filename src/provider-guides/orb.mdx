## What's supported

### Supported actions

This connector supports:

- [Read Actions](/read-actions), including full historic backfill. Please note that incremental read is not supported, a full read of the Orb instance will be done for each scheduled read.

### Notes

- Orb's list endpoints cannot filter by when a record was last changed, and Orb records carry no last-updated timestamp. Each scheduled read therefore returns every record of the object, including ones that have not changed since the previous read.
- `customers` are the buyers you bill, `subscriptions` tie a customer to a plan, `invoices` and `credit_notes` are the billing documents issued to customers, `plans` are your pricing plans, and `items` represent what you sell, referenced by prices and invoice line items.
- Field names are Orb's own snake_case keys, such as `external_customer_id`, `created_at` and `invoice_date`. Nested values arrive as JSON objects and arrays; for example, a subscription includes its `customer` and `plan` objects, and an invoice includes its `line_items`. Timestamps are ISO 8601 strings with a UTC offset.
- An Orb API key belongs to either test mode or live mode, and reads return the data of the mode the key was created in.

### Supported objects

The Orb connector supports reading from the following objects:

- [credit_notes](https://docs.withorb.com/api-reference/credit-note/list-credit-notes)
- [customers](https://docs.withorb.com/api-reference/customer/list-customers)
- [invoices](https://docs.withorb.com/api-reference/invoice/list-invoices)
- [items](https://docs.withorb.com/api-reference/item/list-items)
- [plans](https://docs.withorb.com/api-reference/plan/list-plans)
- [subscriptions](https://docs.withorb.com/api-reference/subscription/list-subscriptions)

### Example integration

To define an integration for Orb, create a manifest file that looks like this:

```YAML
# amp.yaml
specVersion: 1.0.0
integrations:
  - name: orbIntegration
    displayName: My Orb Integration
    provider: orb
    read:
      objects:
        - objectName: customers
          destination: myWebhook
        - objectName: invoices
          destination: myWebhook
```

## Before you get started

To connect Orb with Ampersand, you will need an [Orb account](https://www.withorb.com).

### Creating an API key for Orb

1. Log in to the [Orb web app](https://app.withorb.com).
2. Use the mode switch in the top left to choose test mode or live mode. The key you create reads only that mode's data.
3. Go to **Developers** > [API keys](https://app.withorb.com/api-keys) and create a new API key.
4. Copy the key.

## Using the connector

This connector uses API Key auth, which means that you do not need to set up a Provider App before getting started. (Provider apps are only required for providers that use OAuth2 Authorization Code grant type.)

To start integrating with Orb:

- Create a manifest file like the [example above](#example-integration).
- Deploy it using the [amp CLI](/cli/overview).
- If you are using Read Actions, create a [destination](/destinations).
- Embed the [InstallIntegration](/embeddable-ui-components#install-integration) UI component. The UI component will prompt the customer for their API key.
- Start using the connector!
   - If your integration has [Read Actions](/read-actions), you'll start getting webhook messages.
